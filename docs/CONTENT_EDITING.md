# Editing the site ourselves

Once Phase 2 is live, everything is editable at **`yourdomain.com/studio`** — works on phone too.

## Common edits
| I want to… | Go to |
|---|---|
| Change headline, names, date | **Site Settings** |
| Edit a page's text or reorder sections | **Pages** → pick page → drag sections |
| Add a new page (e.g. "Things to Do") | **Pages** → New → add sections → add to nav in Site Settings |
| Add/change an event | **Events** |
| Add a hotel block | **Hotels** |
| Answer a new FAQ | **FAQ** → New (drag to reorder) |
| Add gallery photos | **Gallery** → drag & drop many at once |
| See who RSVP'd | **RSVPs** (export CSV from the top menu) |
| Add a guest | **Guests** (or send Claude a CSV) |

## Click-to-edit (Visual Editing)
Open **Presentation** in Studio: the live site shows on the right — click any text or photo and its field opens on the left. Changes preview instantly; hit **Publish** to make them live.

## Safety nets
- Every document has **history** — restore any past version.
- **Drafts** aren't public until you click Publish.
- Placeholders are flagged so we never launch with stock photos.
